# Layout

What `p1` is made of, underneath the aspect list. [DENDRITIC.md](DENDRITIC.md)
is how the config is organised; this is the machine it configures.

## Hardware

Thinkpad P1 Gen 7. Intel iGPU at `PCI:0:2:0`, NVIDIA at `PCI:1:0:0`, driven in
offload mode by the `nvidia-prime` aspect. Two NVMe drives, fingerprint reader,
TPM 2.0.

`nix/hosts/p1/hardware.nix` is generated by `nixos-generate-config`. Keep edits
out of it — anything hand-written there is lost the next time it is
regenerated; it belongs in an aspect or in `default.nix`.

## Disks

MDADM RAID0 across both NVMe drives, LUKS2 on top, btrfs inside, declared in
`nix/hosts/p1/disko.nix`. The mdadm "no mail" warning is suppressed because
there is no MTA on this host to send it to.

| subvolume | mounted at | notes |
| --- | --- | --- |
| `/root` | `/` | wiped on every boot, see [the rollback](#impermanence) |
| `/nix` | `/nix` | the store |
| `/home` | `/home` | survives the rollback; the music bind into `/home/kazu` lives here |
| `/persist` | `/persist` | what the rollback is told to keep |
| `/var/log` | `/var/log` | `neededForBoot` |
| `/snapshots` | `/snapshots` | |

All of them mount with `compress=zstd:3`, `noatime`, `discard=async`.

### Impermanence

`root-blank` is a read-only snapshot taken of `/root` at install time, while
the subvolume is still empty. Every boot, an initrd service moves the current
`/root` aside into `/btrfs_tmp/old_roots`, restores `root-blank`, and deletes
old roots older than 30 days — so a mistake is recoverable for a month. What
survives is `/persist`, `/home`, and whatever `environment.persistence` names.

The ssh host keys are in that list deliberately: they are the machine's stable
identity *and* a sops-nix identity, so losing them loses the secrets too.

## Kernel

`linuxPackages_latest`, btrfs and vfat, plus two parameters that are workarounds
rather than preferences:

- `i915.enable_psr=0` — panel self-refresh blanks the internal display on this
  chassis.
- `video=DP-1:d` — DP-1 is a phantom. No DP port exists on this chassis (HDMI
  2.1 is the only non-USB-C output, and it enumerates as HDMI-A-1), but firmware
  hands the kernel a stale "LG TV" EDID for DDI B. Without this, Hyprland
  configures a monitor that is not there and hands it focus. HDMI-A-1 and the
  USB-C outputs (DP-2..DP-5) are unaffected.

## The import list

`nix/hosts/p1/default.nix` is grouped by blank lines, in this order: the
profile and the host's own hardware, then system, network, desktop, dev, AI,
gaming, apps. The groups are a reading aid — nothing in the evaluation cares
about the order.
